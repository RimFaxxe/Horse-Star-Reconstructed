This folder contains minimal reconstructed versions of missing Build_infos.xml files, created using data recovered from the Assembly-CSharp.dll in the Horse Star client.

These are not original game files generated at runtime. They are simplified recreations designed solely for testing and research within this project.

The current versions are incomplete and only sufficient to progress initial loading (e.g. triggering requests for EN_Dialog.txt and Input_DefinitionsQWERTY.txt).

These files are experimental, not finalized, and should not be considered accurate reproductions of the original data.

These files are provided for reference within this repository and are not intended for standalone use.

They are included strictly as part of the ongoing reverse engineering effort.
